🎮 Best Google Fonts for a TLOU2-style website
🔥 1. Bold, Condensed (MAIN HEADLINES)

These give you that harsh, survival-world signage feel:

Oswald → closest to the actual TLOU vibe
Bebas Neue → cinematic, poster-style
Anton → heavy and aggressive
Six Caps → very narrow, military labeling feel

👉 These work perfectly for:

Titles
Section headers
UI labels


📌 Why: Condensed sans-serifs are commonly used for bold, impactful messaging in this style

✍️ 2. Handwritten / Survivor Notes (ACCENT TEXT)
These mimic notes, journals, graffiti:

Permanent Marker → graffiti / wall messages
Rock Salt → rough, emotional writing
Architects Daughter → cleaner notebook feel

👉 Use for:

Quotes
Journal entries
UI flavor text

📌 These styles evoke “desperate messages scrawled on walls or notes”


💻 3. Terminal / Logs (TECH + UI)
Cutive Mono → perfect for logs, data, system text

👉 Use for:

Logs
Stats
Inventory / UI panels

📌 Gives that abandoned tech / system interface feel

📖 4. Body Text (READABILITY + MOOD)
You still need something readable:

Inter → modern, clean (best overall)
Roboto → neutral and widely used
Lora → slightly emotional / story-driven
Open Sans → safe and clean

👉 Use for:

Paragraphs
UI text
Forms

📌 Google Fonts offers tons of free, web-optimized typefaces for readability
